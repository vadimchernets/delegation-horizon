# F5. Agentic skills and matching rule (DRAFT)

- Taxonomy: Lightcast Open Skills, the release current on the registration date; its version number is written here on that day.
- Agentic skill list (frozen): AI Agents; Agentic AI; Multi-Agent Systems; Autonomous Agents; LangChain; LangGraph; CrewAI; AutoGen; Model Context Protocol; Agent Orchestration; Claude Code; GitHub Copilot Agent; OpenAI Codex; Prompt Engineering for Agents; Tool Use (LLM); Retrieval-Augmented Generation; AI Workflow Automation. Lightcast skills named in Lightcast (2026a) are added by exact skill ID on the registration day.
- Population: US postings in SOC 15-1200 (computer occupations), 6-digit codes frozen.
- Treatment: a posting lists at least one skill from the list. Control: a posting with none of them.
- Matching: exact on SOC 6-digit code, seniority band (Lightcast experience requirement: 0-2, 3-5, 6+ years), state and calendar quarter. Cells with fewer than 20 postings on either side are dropped.
- Outcome: share requiring a bachelor's degree or higher (Lightcast minimum education field).
- Estimate: difference treated minus control, weighted by treated postings per cell; 95% interval by cell bootstrap (1,000 draws).
- Baseline: the same computation for 2026 Q2 and Q3, archived before registration.
